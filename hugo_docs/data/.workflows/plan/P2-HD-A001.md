## Interface Contract

**Creates (data — the interface phase 3 consumes):**

`hugo_docs/data/popup_cards/<card-id>.yaml` — 10 files. Exactly four scalar keys:

| key | type | meaning |
|---|---|---|
| `section` | string, one of `agents` \| `screener` \| `features` | which `<section id>` the card's grid lives in |
| `heading` | string | the exact `<h4>` inner text **after** the `<svg>`, HTML entities **as authored** (`Performance &amp; Architecture`) — phase 3 must emit it with `safeHTML` |
| `icon` | string, `ic-*` | the fragment id for `<use href="#...">` |
| `order` | int | position of the card **within its section**, in tens |

`hugo_docs/data/popups/<popup-id>.yaml` — 51 files, **the filename is the popup id**. Exactly four
keys:

| key | type | meaning |
|---|---|---|
| `card` | string | must equal the basename of an existing `popup_cards/*.yaml` (phase 3 guard G1) |
| `order` | int | position within that card, in tens; unique per card (guard G3) |
| `label` | string | the exact trigger-button inner text, entities **as authored** — `safeHTML` |
| `body` | string, YAML literal block scalar with an **explicit indentation indicator** (`\|2`) | the dedented raw HTML, `<h2>` **included verbatim** — `safeHTML` |

**Creates (script):** `hugo_docs/scripts/popups_emit.py` — the YAML-emitting half. It imports
`norm` **and the four decision-D1 constants** from `popups_extract` and defines none of its own.

> **`order` is a bare YAML integer, and nothing asserts a language-level `int` on it.**
> Hugo decodes a positive YAML integer as `uint64` (phase-3 finding F9), so a template assertion
> written as `ne (printf "%T" $p.order) "int"` would fire on all 61 files. Phase 3 therefore
> asserts *presence* with `isset` and normalises with `int` in the sort key. On the Python side
> `popups_emit.py check` compares the PyYAML-decoded value to the plan record (both plain Python
> ints) and never inspects a type name, and `popups_extract.py` never sees `order` at all — the
> baseline carries trigger *position*, and this phase derives `order` from it. There is no
> `int`-type assumption anywhere in the set to align.

**Requires (from Phase 1):**
- `popups_extract.norm(s) -> str` importable as a module-level function, implementing I1's five
  steps, returning a string ending in exactly one `\n`.
- `popups_extract.SPLIT_ID`, `SPLIT_NEW_ID`, `SPLIT_CARD`, `SPLIT_OCCURRENCE` — the decision-D1
  names, declared **once**, in phase 1 (phase-1.md Interface Contract §2(ii)). This phase imports

- `hugo_docs/scripts/popups_baseline.json` containing, for all **51 case occurrences** (both

  the **10 cards in source order** with `section`, `heading`, `icon`, and their trigger list in
  **trigger order** with `id` and `label`. The exact key spellings this phase reads, and the
  tolerant adapter that absorbs minor differences, are in Step 2.

**Leaves alone (owned by others):**
- `hugo_docs/layouts/page/custom-home.html` — Phase 3. **Not read at runtime by this phase either**;
  everything comes from the baseline.
- `popups_verify.py`, `popups_baseline.json`, `popups_extract.py`'s `norm()` and parse side — Phase 1.
- `content/docs/**`, `public/**`, `themes/`, `resources/`, `~/agentic_golang`.

## Findings that change the work (measured in this worktree, not assumed)

**F1 — `hugo_docs/data/` does not exist.** The analysis says it "exists and is EMPTY" (`:verified
state` table). Git cannot track an empty directory, so a fresh worktree has none:

```
$ ls -la /home/miftah/.worktrees/agentic/popup-data-refactor/hugo_docs/data/
ls: cannot access '.../hugo_docs/data/': No such file or directory
```

The generator must `mkdir -p` both trees. Harmless, but a generator that assumed the directory
would fail on first run.

**F2 — `norm()` does NOT flatten 15 of the 51 bodies to column 0, and it must not.** `norm` removes
the longest common leading-whitespace prefix of all *non-blank* lines. Fifteen bodies contain a
block that already sits at column 0 in the source — the 13 `<div class="mermaid">` graph sources and
the 2 `<pre><code>` blocks — so their common prefix is empty and the surrounding prose keeps its
authoring indentation:

```
$ python3 -c "...first-line indent of each normed body..."
server-owned-routing         first-line indent=4      ← era-0 bodies
image-pipeline               first-line indent=4
screener-lock                first-line indent=4
cache-fastlane               first-line indent=4
parallel-map-execution       first-line indent=4
stateful-conversation        first-line indent=4
data-driven-tools            first-line indent=4
citations                    first-line indent=4
file-asset-integrity         first-line indent=4
bowl-resume                  first-line indent=16     ← era-8 bodies
circuit-breakers             first-line indent=16
e2e-cancellation             first-line indent=16
structured-logging           first-line indent=16
observability-stack          first-line indent=16
status-tracking              first-line indent=16
```

Two consequences, both load-bearing:

1. **R3's scope is exactly what D2 licenses, no more.** 36 of 51 bodies flatten to column 0 and the
   two authoring eras vanish for them. For the other 15 the residual 4-vs-16 indentation is
   *content* — dedenting it further would change bytes relative to the whitespace-significant
   `<pre>`/mermaid blocks and break I1, which is byte-for-byte *after the same `norm`*. R3 is
   therefore realised as: **one uniform carrier shape** (identical header layout, identical 2-space
   block-scalar indent, identical `norm` applied to every body regardless of era) rather than "one
   uniform column". Do not hand-reindent the 15. Do not add a second, stronger normaliser — phase 2
   is forbidden from touching `norm()`, and a second one is how this refactor silently fails.
2. **The emitted block scalar MUST carry an explicit indentation indicator.** A plain `body: |`
   whose first content line begins with a space is a YAML error or, worse, a silent misparse. All
   15 of the above begin with spaces. The generator therefore always emits **`body: |2`** — never a
   bare `|`, never a case-by-case choice. Verified against Hugo's own parser below.

**F3 — the trigger-label-vs-`<h2>` trap, swept exhaustively.** Every one of the 51 trigger labels
was compared against its body's `<h2>` inner text. Exactly two differ:

```
MISMATCH screener-content-is-routing  label='Content Is the Routing'
                                      h2   ='Content Is the Routing; the Label Only Lies'
MISMATCH dark-launch                  label='Dark-Launch Feature Flags'
                                      h2   ='Dark-Launch Flag Discipline'
```

The second is not a real divergence — it is the D1 bug itself (the System Observability button
opening the Multimodal body). The split fixes it: `feature-flags`'s resurrected body opens
`<h2>Dark-Launch Feature Flags</h2>`, which equals its label. So **after D1 exactly one id,
`screener-content-is-routing`, has `label != <h2>`**. The `<h2>` stays inside `body` verbatim and
`label` is its own field for all 51 — the generator never reconstructs one from the other, and a
`--check` assertion records (not enforces) the one divergence so a future drift is visible.

**F4 — Hugo v0.164.0 round-trips `|2` block scalars byte-for-byte.** Measured, not assumed. A
throwaway site in the scratchpad with the 61 generated files and the one-line carrier template from
decision D4:

```
$ ~/bin/hugo --quiet --destination .../hugotest/public
BUILD OK
rendered ids: 51
hugo-side byte mismatches: 0
```

This covers the whole hazard surface in one shot: the 15 indented-first-line bodies, the 2 `<pre>`
blocks, the 13 mermaid sources, UTF-8 em-dashes, `&amp;`/`&lt;` entities (undecoded), `#` and `:`
inside prose, and the single backslash.

**F5 — the one JS escape survives the whole chain.** `custom-home.html:2842` holds `"\\n"` inside a
template literal, which the browser renders as one backslash + `n`. Phase 1's extractor unwinds it;
the block scalar carries it with no re-escaping:

```
RAW FILE : '  <p>...<code>timestamp + "\\n" + secret</code>...'    ← repr(): one backslash
PARSED   : '<p>...<code>timestamp + "\\n" + secret</code>...'      ← via PyYAML
HUGO-OUT : '<p>...<code>timestamp + "\\n" + secret</code>...'      ← via Hugo + safeHTML
```

**F6 — ordering really does come from the triggers, not the switch.** Confirmed in the live file:
`Resource Management`'s buttons at `:588`–`:594` run `bowl-resume, e2e-cancellation, janitors,
stale-while-revalidate, consul-discovery, circuit-breakers, usage-limits`, while the switch at
`:2271`+ runs a different sequence. The generator derives `order` **only** from the baseline's card
trigger lists and never looks at case order.

**Code:**

```python
#!/usr/bin/env python3
"""Emit the Hugo popup data tree from the phase-1 baseline.

    python3 hugo_docs/scripts/popups_emit.py emit [--force]
    python3 hugo_docs/scripts/popups_emit.py check

`emit` writes hugo_docs/data/popup_cards/*.yaml (10) and hugo_docs/data/popups/*.yaml (51)
from hugo_docs/scripts/popups_baseline.json, applying decision D1 (the dark-launch split).
`check` reads those files back and asserts, for every id, that the body is byte-identical to
the baseline body, plus the referential-integrity properties phase 3 turns into build guards.

This is a BOOTSTRAP tool. Once the tree is committed the YAML files are the source of truth;
re-running `emit` without --force refuses to clobber them. `check` stays useful forever.

norm() is NOT defined here. It is imported from popups_extract, which owns it. Two norm()s is
how this refactor silently fails.
"""

from __future__ import annotations

import argparse
import html
import json
import re
import sys
from pathlib import Path

HERE = Path(__file__).resolve().parent          # hugo_docs/scripts
HUGO = HERE.parent                              # hugo_docs
sys.path.insert(0, str(HERE))

# --- Decision D1: the dark-launch split ------------------------------------
# The id `dark-launch` is declared twice in the switch. The first (live) body stays in the
# Multimodal Processing card under the id it has. The second (dead) body is resurrected under
# a NEW id in the System Observability card, where its trigger button already sits and already
# reads "Dark-Launch Feature Flags". Nothing is dropped. This is the one sanctioned content
# change in the whole refactor; see POPUP_DATA_REFACTOR_PLAN.md, Decisions table, D1.
#
# These names are NOT re-declared here. popups_extract.py owns them, popups_verify.py imports
# them, and so does this module: one definition, so the emitter and the checker cannot disagree
# about which body `feature-flags` gets.
from popups_extract import (                   # noqa: E402  (phase 1 owns all of this)
    SPLIT_CARD,
    SPLIT_ID,
    SPLIT_NEW_ID,
    SPLIT_OCCURRENCE,
    norm,
)

BASELINE_PATH = HERE / "popups_baseline.json"
DATA_DIR = HUGO / "data"
POPUPS_DIR = DATA_DIR / "popups"
CARDS_DIR = DATA_DIR / "popup_cards"

# Card ids are PINNED, not merely derived. Phase 3's build guard G1 fails on a typo here, and a
# future change to slugify() must not silently rename a data file. Keys are the <h4> inner text
# exactly as authored, entities included.
CARD_IDS = {
    "Multi-Agent System": "multi-agent-system",
    "Multimodal Processing": "multimodal-processing",
    "The Lock": "the-lock",
    "Planning a Turn": "planning-a-turn",
    "The Measured API": "the-measured-api",
    "Shape of the Tool": "shape-of-the-tool",
    "Performance &amp; Architecture": "performance-architecture",
    "Resource Management": "resource-management",
    "Data Handling &amp; Integrity": "data-handling-integrity",
    "System Observability": "system-observability",
}

SECTIONS = ("agents", "screener", "features")

HEADER = (
    "# Generated once by hugo_docs/scripts/popups_emit.py; this file is now the source of truth.\n"
    "# Edit the prose here. `popups_emit.py check` re-asserts it against popups_baseline.json.\n"
)

BLOCK_INDENT = 2


# --------------------------------------------------------------------------- baseline adapter
class BaselineError(RuntimeError):
    pass


def _pick(d: dict, *names: str):
    """Return the first present key among `names`, or raise naming what was actually there."""
    for n in names:
        if n in d:
            return d[n]
    raise BaselineError(
        "popups_baseline.json: expected one of %r, found keys %r"
        % (list(names), sorted(d.keys()))
    )


def load_baseline(path: Path = BASELINE_PATH):
    """Normalise phase 1's baseline into (occurrences, cards).

    occurrences: list of {"id", "body", "line"} for all 51 `case` occurrences, in SOURCE ORDER.
                 Both dark-launch entries are present and distinguished by position.
    cards:       list of {"section", "heading", "icon", "triggers": [{"id", "label"}]},
                 in SOURCE ORDER, each trigger list in TRIGGER ORDER (never switch order).
    """
    raw = json.loads(path.read_text(encoding="utf-8"))

    raw_occ = _pick(raw, "occurrences", "bodies", "cases", "popups")
    if isinstance(raw_occ, dict):
        # tolerated shape: {key: {...}} — order is recovered from the line number
        raw_occ = list(raw_occ.values())
    occurrences = []
    for o in raw_occ:
        occurrences.append(
            {
                "id": _pick(o, "id", "popup_id", "case"),
                "body": _pick(o, "body", "html", "content"),
                "line": int(_pick(o, "line", "case_line", "lineno", "start_line")),
            }
        )
    occurrences.sort(key=lambda o: o["line"])

    raw_cards = _pick(raw, "cards", "feature_cards", "popup_cards")
    cards = []
    for c in raw_cards:
        raw_trigs = _pick(c, "triggers", "popups", "buttons", "items")
        cards.append(
            {
                "section": _pick(c, "section"),
                "heading": _pick(c, "heading", "title", "h4"),
                "icon": _pick(c, "icon"),
                "triggers": [
                    {"id": _pick(t, "id", "popup_id"), "label": _pick(t, "label", "text")}
                    for t in raw_trigs
                ],
            }
        )

    if len(occurrences) != 51:
        raise BaselineError("expected 51 case occurrences, got %d" % len(occurrences))
    if len(cards) != 10:
        raise BaselineError("expected 10 cards, got %d" % len(cards))
    n_trig = sum(len(c["triggers"]) for c in cards)
    if n_trig != 51:
        raise BaselineError("expected 51 triggers, got %d" % n_trig)
    for c in cards:
        if c["section"] not in SECTIONS:
            raise BaselineError("unknown section %r on card %r" % (c["section"], c["heading"]))
    return occurrences, cards


def body_for(occurrences, popup_id: str, nth: int = 0) -> str:
    """The nth (0-based, source order) `case` body for popup_id, normalised."""
    hits = [o for o in occurrences if o["id"] == popup_id]
    if len(hits) <= nth:
        raise BaselineError("no occurrence #%d of case %r in the baseline" % (nth, popup_id))
    return norm(hits[nth]["body"])


# --------------------------------------------------------------------------- YAML emission
def slugify(heading: str) -> str:
    s = html.unescape(heading).lower()
    return re.sub(r"[^a-z0-9]+", "-", s).strip("-")


def card_id_for(heading: str) -> str:
    try:
        pinned = CARD_IDS[heading]
    except KeyError:
        raise BaselineError(
            "card heading %r is not in CARD_IDS. A new card needs a pinned id here, "
            "because phase 3's guard G1 and every popup's `card:` field spell it out." % heading
        )
    derived = slugify(heading)
    if derived != pinned:
        raise BaselineError(
            "pinned card id %r disagrees with slugify(%r) = %r" % (pinned, heading, derived)
        )
    return pinned


def yaml_scalar(s: str) -> str:
    """A double-quoted YAML scalar. Entities stay as authored; nothing is decoded."""
    if "\n" in s or "\r" in s or "\t" in s:
        raise ValueError("control character in scalar: %r" % s)
    return '"' + s.replace("\\", "\\\\").replace('"', '\\"') + '"'


def yaml_block(body: str, indent: int = BLOCK_INDENT) -> str:
    """A literal block scalar with an EXPLICIT indentation indicator.

    `|%d` rather than a bare `|` because 15 of the 51 bodies legitimately begin with leading
    whitespace (finding F2) — mermaid and <pre> bodies whose common prefix norm() cannot strip.
    With a bare `|` YAML infers the indent from the first non-empty line, which for those bodies
    is wrong. The explicit indicator makes the parse independent of the content.

    `|` (clip chomping) keeps exactly one trailing newline, which is what norm() guarantees.
    """
    if not body.endswith("\n"):
        raise ValueError("body does not end in a newline — norm() was not applied")
    if body.endswith("\n\n"):
        raise ValueError("body ends in more than one newline — norm() was not applied")
    if not body.strip():
        raise ValueError("empty body")
    if "</script>" in body:
        raise ValueError("body contains </script>; it cannot ride in a script carrier")
    if "\t" in body:
        raise ValueError("body contains a tab; the page region has none and a tab breaks dedent")
    pad = " " * indent
    out = ["|%d" % indent]
    for line in body[:-1].split("\n"):
        if line and line.rstrip() != line:
            print("warn: trailing whitespace preserved verbatim: %r" % line, file=sys.stderr)
        out.append(pad + line if line else "")
    return "\n".join(out) + "\n"


def card_yaml(section: str, heading: str, icon: str, order: int) -> str:
    return (
        HEADER
        + "section: %s\n" % section
        + "heading: %s\n" % yaml_scalar(heading)
        + "icon:    %s\n" % icon
        + "order:   %d\n" % order
    )


def popup_yaml(card: str, order: int, label: str, body: str) -> str:
    return (
        HEADER
        + "card:  %s\n" % card
        + "order: %d\n" % order
        + "label: %s\n" % yaml_scalar(label)
        + "body: " + yaml_block(body)
    )


# --------------------------------------------------------------------------- plan + write
def build_plan(occurrences, cards):
    """(card_records, popup_records). Pure: no I/O, so `check` reuses it verbatim."""
    seen_occ = {}          # popup id -> how many case occurrences consumed so far
    section_order = {}
    card_records, popup_records = [], []

    for card in cards:
        cid = card_id_for(card["heading"])
        section_order[card["section"]] = section_order.get(card["section"], 0) + 10
        card_records.append(
            {
                "id": cid,
                "section": card["section"],
                "heading": card["heading"],
                "icon": card["icon"],
                "order": section_order[card["section"]],
            }
        )
        for i, trig in enumerate(card["triggers"]):
            src_id = trig["id"]
            nth = seen_occ.get(src_id, 0)
            seen_occ[src_id] = nth + 1
            out_id = src_id
            if src_id == SPLIT_ID and cid == SPLIT_CARD:
                out_id = SPLIT_NEW_ID          # D1
                nth = SPLIT_OCCURRENCE         # 1: the DEAD :2885 body, not the live :1754 one
            popup_records.append(
                {
                    "id": out_id,
                    "card": cid,
                    "order": (i + 1) * 10,
                    "label": trig["label"],
                    "body": body_for(occurrences, src_id, nth),
                }
            )
    return card_records, popup_records


def integrity(card_records, popup_records) -> list[str]:
    """Pre-flight for phase 3's build guards G1-G3, plus the content assertions."""
    errs = []
    card_ids = {c["id"] for c in card_records}
    if len(card_ids) != len(card_records):
        errs.append("duplicate card id")
    popup_ids = [p["id"] for p in popup_records]
    if len(set(popup_ids)) != len(popup_ids):
        dupes = sorted({i for i in popup_ids if popup_ids.count(i) > 1})
        errs.append("G0 duplicate popup id (filename collision): %s" % dupes)
    for p in popup_records:
        if p["card"] not in card_ids:
            errs.append("G1 popup %r names unknown card %r" % (p["id"], p["card"]))
        if not p["label"].strip():
            errs.append("empty label on %r" % p["id"])
        if not p["body"].strip():
            errs.append("empty body on %r" % p["id"])
        if "</script>" in p["body"]:
            errs.append("</script> in body of %r" % p["id"])
    for cid in card_ids:
        mine = [p for p in popup_records if p["card"] == cid]
        if not mine:
            errs.append("G2 card %r has no popups" % cid)
        orders = [p["order"] for p in mine]
        if len(set(orders)) != len(orders):
            errs.append("G3 order collision in card %r: %s" % (cid, sorted(orders)))
    return errs


def cmd_emit(force: bool) -> int:
    occurrences, cards = load_baseline()
    card_records, popup_records = build_plan(occurrences, cards)
    errs = integrity(card_records, popup_records)
    if errs:
        for e in errs:
            print("ERROR %s" % e, file=sys.stderr)
        return 1

    for d in (CARDS_DIR, POPUPS_DIR):
        d.mkdir(parents=True, exist_ok=True)          # finding F1: data/ does not exist
        existing = sorted(d.glob("*.yaml"))
        if existing and not force:
            print(
                "refusing to overwrite %d file(s) in %s; these YAML files are the source of "
                "truth now. Pass --force only to re-bootstrap from the baseline."
                % (len(existing), d),
                file=sys.stderr,
            )
            return 1

    for c in card_records:
        (CARDS_DIR / ("%s.yaml" % c["id"])).write_text(
            card_yaml(c["section"], c["heading"], c["icon"], c["order"]), encoding="utf-8"
        )
    for p in popup_records:
        (POPUPS_DIR / ("%s.yaml" % p["id"])).write_text(
            popup_yaml(p["card"], p["order"], p["label"], p["body"]), encoding="utf-8"
        )

    print("wrote %d popup_cards + %d popups = %d files"
          % (len(card_records), len(popup_records), len(card_records) + len(popup_records)))
    return 0


def cmd_check() -> int:
    try:
        import yaml  # PyYAML, dev-time only; Hugo is the authoritative parser (see Step 4)
    except ImportError:
        print("check needs PyYAML (pip install --user pyyaml). The `hugo` build in the exit "
              "criteria is the authoritative parse check; this is the byte-level one.",
              file=sys.stderr)
        return 2

    occurrences, cards = load_baseline()
    card_records, popup_records = build_plan(occurrences, cards)

    fails = 0
    on_disk_popups = sorted(p.stem for p in POPUPS_DIR.glob("*.yaml"))
    on_disk_cards = sorted(c.stem for c in CARDS_DIR.glob("*.yaml"))
    if on_disk_popups != sorted(p["id"] for p in popup_records):
        print("FAIL popups/ on disk does not match the plan", file=sys.stderr)
        fails += 1
    if on_disk_cards != sorted(c["id"] for c in card_records):
        print("FAIL popup_cards/ on disk does not match the plan", file=sys.stderr)
        fails += 1

    for c in card_records:
        d = yaml.safe_load((CARDS_DIR / ("%s.yaml" % c["id"])).read_text(encoding="utf-8"))
        for k in ("section", "heading", "icon", "order"):
            if d.get(k) != c[k]:
                print("FAIL card %s.%s: %r != %r" % (c["id"], k, d.get(k), c[k]), file=sys.stderr)
                fails += 1

    h2_re = re.compile(r"<h2>(.*?)</h2>", re.S)
    divergent = []
    for p in popup_records:
        d = yaml.safe_load((POPUPS_DIR / ("%s.yaml" % p["id"])).read_text(encoding="utf-8"))
        for k in ("card", "order", "label"):
            if d.get(k) != p[k]:
                print("FAIL %s.%s: %r != %r" % (p["id"], k, d.get(k), p[k]), file=sys.stderr)
                fails += 1
        # the property this whole phase exists to guarantee
        if norm(d.get("body") or "") != p["body"]:
            print("FAIL body round trip: %s" % p["id"], file=sys.stderr)
            fails += 1
        m = h2_re.search(d.get("body") or "")
        if m and m.group(1) != p["label"]:
            divergent.append((p["id"], p["label"], m.group(1)))

    errs = integrity(card_records, popup_records)
    for e in errs:
        print("FAIL %s" % e, file=sys.stderr)
    fails += len(errs)

    for pid, label, h2 in divergent:
        print("note: label != <h2> for %s: %r vs %r" % (pid, label, h2))
    if len(divergent) != 1 or divergent[0][0] != "screener-content-is-routing":
        print("FAIL expected exactly one label/<h2> divergence "
              "(screener-content-is-routing); got %r" % [d[0] for d in divergent],
              file=sys.stderr)
        fails += 1

    print("checked %d cards + %d popups; failures: %d"
          % (len(card_records), len(popup_records), fails))
    return 1 if fails else 0


def main(argv=None) -> int:
    ap = argparse.ArgumentParser(description=__doc__.split("\n")[0])
    sub = ap.add_subparsers(dest="cmd", required=True)
    e = sub.add_parser("emit", help="write the data tree from the baseline")
    e.add_argument("--force", action="store_true", help="overwrite an existing data tree")
    sub.add_parser("check", help="assert the data tree against the baseline")
    args = ap.parse_args(argv)
    try:
        return cmd_emit(args.force) if args.cmd == "emit" else cmd_check()
    except BaselineError as exc:
        print("baseline error: %s" % exc, file=sys.stderr)
        return 2


if __name__ == "__main__":
    raise SystemExit(main())
```

### Step 4: The YAML round-trip guarantee, and the dependency question

**Change:** no file; this records the decision the phase scope asked to be stated.

**How the round trip is guaranteed — four independent layers:**

1. **Emission is a hand-rolled stdlib writer.** `yaml_block()` produces a literal block scalar with
   an explicit indentation indicator and clip chomping, byte by byte. No serialiser heuristics are
   in play: no line folding, no quoting choice, no re-encoding, no `allow_unicode` setting to get
   wrong. The `emit` path imports nothing outside the standard library plus phase 1's `norm`.
2. **`|2`, never a bare `|`.** Finding F2 — 15 bodies begin with leading whitespace; a bare `|`
   would infer the block indent from them and misparse. The explicit indicator makes the parse a
   function of the indicator alone.
3. **Clip chomping matches `norm`.** `|` (clip) yields content ending in exactly one `\n`, which is
   `norm`'s step 5. `|-` would strip it and `|+` would keep all of them; both fail `check`.
   `yaml_block` asserts the input ends in exactly one newline before writing, so a `norm` that
   stopped guaranteeing it fails loudly rather than producing a drifted file.
4. **The round trip is asserted, twice, by different parsers.** `popups_emit.py check` loads every
   file with PyYAML and asserts `norm(yaml_body) == baseline_body` byte-for-byte. The exit criteria
   additionally build with `~/bin/hugo`, whose **own** Go YAML parser is the one that actually
   matters in production.

**The PyYAML question, answered explicitly.** PyYAML 6.0.2 is present in this environment, but
**this repo declares no Python dependencies** — there is no `requirements.txt`, no
`pyproject.toml`, and `.github/workflows/deploy.yml` runs only Hugo. So PyYAML is *not* "already
available in this repo" in the sense that matters, and this phase does not make it one:

- the **emit** path is stdlib-only and will run on a bare Python 3;
- **`check`** imports PyYAML lazily, inside the function, and on `ImportError` prints the install
  line and returns 2 — a distinct exit code, not a crash and not a silent pass;
- nothing in CI calls either script, so the deploy pipeline gains no dependency;
- the authoritative parse check is the `hugo` build, which has no Python in it at all.

No dependency file is added and none is needed. If a future reviewer wants `check` to be
dependency-free, the replacement is a ~30-line block-scalar reader, not a new requirement — noted
in Handoffs.

## Assumptions

**About Phase 1** — written before phase-1.md existed, **since verified against it by the
reconciler. A1–A5 all hold as stated; nothing below needs changing.** Kept as the record of what
this phase requires, so a future change to phase 1 can be checked against it:

- **A1.** `popups_extract.py` exposes `norm(s) -> str` at module level, importable as
  `from popups_extract import norm`, with no side effects at import time (no `argparse` call, no
  file read outside `if __name__ == "__main__":`). If phase 1 puts `norm` elsewhere, only the one
  import line changes.
- **A2.** `popups_baseline.json` carries **all 51 case occurrences** — both dark-launch bodies —
  each with its source `case` line number so the live `:1754` and dead `:2885` bodies are
  distinguishable by position. If phase 1 de-duplicates to 50, D1 cannot be implemented from the
  baseline and phase 1 must be amended; `load_baseline()` fails loudly with
  `expected 51 case occurrences, got 50` rather than producing a wrong `feature-flags`.
- **A3.** The baseline carries the 10 cards in source order with their trigger lists in **trigger
  order**, each with `section`, `heading`, `icon`, and per trigger `id` and `label` — the plan
  index's phase-1 description says exactly this ("all 51 triggers (with card, icon, section,
  order)"). This phase deliberately contains **no second parser** of `custom-home.html`; ordering
  comes from the baseline or the run fails.
- **A4.** Baseline bodies are already `norm`-ed and JS-unescaped (the `"\\n"` at `:2842` reduced to
  one backslash). `popups_emit.py` re-applies `norm` anyway — it is idempotent, so this is free
  insurance against a baseline that skipped step 5.
- **A5.** `load_baseline()`'s `_pick()` accepts several plausible key spellings and raises an error
  naming the keys it actually found. **Verified by the reconciler against phase-1.md's baseline
  schema: `_pick` is a no-op.** Every key this phase tries *first* is exactly the key phase 1
  emits — `occurrences` / `id` / `body` / `line`, and `cards` / `section` / `heading` / `icon` /
  `triggers` / `id` / `label`. The extra keys phase 1 also writes (`close_line`, `indent`, and
  `line` on cards and triggers) are ignored harmlessly. `_pick` is left in place as a loud failure
  mode for a future re-shaped baseline; it changes no behaviour today.

**About Phase 3:** it consumes only the field names and value shapes in the Interface Contract
above. It needs no card-id list of its own — it ranges over `hugo.Data.popup_cards` filtered by
`section` and sorted by `order`, then over the popups filtered by `card`, sorted by `(order, id)`.
**`hugo.Data`, never `.Site.Data`:** the latter was deprecated in Hugo v0.156.0 and logs a WARN on
v0.164.0, which invariant I3 forbids (phase-3 finding F7). The pinned `CARD_IDS` table exists so a
typo in a `card:` field is impossible rather than merely caught by G1.
